📂 Firebase Google Sign-In Practice 
 
This repository contains my practice work created while learning Firebase Authentication in Android. It demonstrates the implementation of Google Sign-In using Firebase, allowing users to authenticate securely with their Google accounts.

📚 About
The purpose of this project is to understand how Firebase Authentication works in Android applications and how Google Sign-In can be integrated to provide a seamless login experience.

🚀 Topics Covered

Firebase Project Setup
Connecting Android App with Firebase
Firebase Authentication Integration
Google Sign-In Configuration
SHA-1 Key Setup
Handling Sign-In & Sign-Out
User Data Retrieval (Name, Email, Profile Photo)
Session Management

📦 Firebase Services Practiced

Firebase Authentication
Google Sign-In Provider

🛠️ Tech Used

Android Studio
Java / Kotlin
Firebase Console
Google Cloud Console

🎯 Learning Outcome

Through this project, I learned:

How to connect an Android app with Firebase
Implementing Google Sign-In using Firebase Authentication
Managing user login sessions
Retrieving authenticated user details
Handling authentication success & failure cases
